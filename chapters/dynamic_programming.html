Dynamic Programming

A hands-on companion to Chapter 4 of Sutton & Barto, Reinforcement Learning: An Introduction.

In the previous chapter we defined \(v_\pi\), \(q_\pi\) and the Bellman equations; now we turn them into algorithms that compute optimal policies when we have a perfect model \(p(s'\mid s,a)\) of the environment.

We work through the dynamic programming toolkit, building each piece symbolically in PyTensor:

  1. Policy evaluation - compute \(v_\pi\) for a fixed policy by iterating the Bellman expectation backup.
  2. Policy improvement - act greedily w.r.t. \(v_\pi\); the policy improvement theorem says this can only help.
  3. Policy iteration - alternate the two until the policy stops changing.
  4. Value iteration - collapse evaluation to a single sweep using the Bellman optimality backup.
  5. Asynchronous DP - drop the rigid full-sweep structure; update states in place, in any order.
  6. Generalized policy iteration (GPI) - the unifying view: any interleaving of evaluation and improvement.

Everything below is one of these two one-line operators applied over and over:

\[ \underbrace{v(s)\leftarrow \sum_a \pi(a\mid s)\sum_{s'} p(s'\mid s,a)\big[r + \gamma v(s')\big]}_{\textbf{expectation backup (evaluation)}} \qquad \underbrace{v(s)\leftarrow \max_a \sum_{s'} p(s'\mid s,a)\big[r + \gamma v(s')\big]}_{\textbf{optimality backup (value iteration)}} \]

Both are \(\gamma\)-contractions, which is why iterating them converges.

Gridworld

As an example we will use the Gridworld example, introduced in the chapter as the following:

A \(4\times4\) grid of 16 states. The two shaded corners, the top-left (state 0) and bottom-right (state 15), are terminal. From any non-terminal state the four actions up, down, left, right move deterministically one cell; an action that would step off the grid leaves the agent where it is.

Every transition earns a reward of \(-1\) until the terminal state is reached, so the task is undiscounted (\(\gamma = 1\)) and episodic; the agent wants to escape to a corner in as few steps as possible. Terminal states are absorbing with value pinned to \(0\).

As in the previous chapter the whole MDP lives in two arrays \(P[s,a,s']=p(s'\mid s,a)\) and \(R[s,a,s']=r(s,a,s')\), here both deterministic.

def grid_xy(s, shape):
    """Convert a state id to (x, y) plot coordinates, with grid row 0 drawn at the top.

    Parameters
    ----------
    s : int
        The state, numbered ``row * n_cols + col``.
    shape : tuple of (int, int)
        The grid's (n_rows, n_cols).

    Returns
    -------
    x, y : int
        The column, and the row counted up from the bottom.
    """
    n_rows, n_cols = shape
    row, col = divmod(int(s), n_cols)
    return col, n_rows - 1 - row

def grid_panels(panel_titles, shape, title="", n_panel_cols=None, cell_px=100, theme=GRID_LIGHT):
    """Make an empty figure with one subplot per panel, each holding a grid of square cells.

    The figure is tall enough for every cell to be ``cell_px`` pixels high and takes the page
    width; the cells stay square. The panels are laid out left to right, then top to bottom.

    Parameters
    ----------
    panel_titles : list of str
        One title per panel.
    shape : tuple of (int, int)
        The (n_rows, n_cols) of the grid. Every panel shares it.
    title : str, default ""
        The figure title. Plotly HTML (<b>, <br>, <sup>) works.
    n_panel_cols : int, optional
        Panels per row of the figure. The default puts every panel in one row.
    cell_px : int, default 100
        Height of one grid cell, in pixels.
    theme : GridTheme, default GRID_LIGHT
        The plotly template and plot background. GRID_DARK for the book's dark theme.

    Returns
    -------
    plotly.graph_objects.Figure
        The figure, with the axes of every panel hidden and scaled so the cells are square.
    """
    n_rows, n_cols = shape
    n_panels = len(panel_titles)
    n_panel_cols = n_panel_cols or n_panels
    n_panel_rows = -(-n_panels // n_panel_cols) # ceiling division
    gap_x_px, gap_y_px = 20, 40 # between panels
    plot_width = n_panel_cols * n_cols * cell_px + (n_panel_cols - 1) * gap_x_px
    plot_height = n_panel_rows * n_rows * cell_px + (n_panel_rows - 1) * gap_y_px

    fig = make_subplots(
        rows=n_panel_rows,
        cols=n_panel_cols,
        subplot_titles=[f"<b>{t}</b>" for t in panel_titles],
        horizontal_spacing=gap_x_px / plot_width,
        vertical_spacing=gap_y_px / plot_height
    )

    for row in range(1, n_panel_rows + 1):
        for col in range(1, n_panel_cols + 1):
            x_axis = fig.get_subplot(row, col).xaxis.plotly_name.replace("axis", "")
            fig.update_xaxes(range=[-0.55, n_cols - 0.45], visible=False, constrain="domain",
                             row=row, col=col)
            fig.update_yaxes(range=[-0.55, n_rows - 0.45], visible=False, scaleanchor=x_axis,
                             constrain="domain", row=row, col=col)

    margin = dict(l=10, r=10, b=10, t=(80 if title else 0) + 30)
    fig.update_layout(
        title=title,
        height=plot_height + margin["t"] + margin["b"],
        margin=margin,
        template=theme.template,
        plot_bgcolor=theme.background,
        showlegend=False
    )
    return fig

def draw_cells(fig, shape, fills, labels, row=1, col=1, pad=0.04):
    """Draw one filled square per state into a subplot, with an optional label on top.

    Parameters
    ----------
    fig : plotly.graph_objects.Figure
        A figure from `grid_panels`. It is changed in place.
    shape : tuple of (int, int)
        The grid's (n_rows, n_cols).
    fills : list of str, length n_rows * n_cols
        The fill color of each state's cell.
    labels : dict of {int: str}
        Text drawn in the middle of a cell, by state, e.g. ``{0: "T"}``.
    row, col : int, default 1, 1
        The panel to draw into.
    pad : float, default 0.04
        Gap around each cell, in cell widths.
    """
    n_rows, n_cols = shape
    for s in range(n_rows * n_cols):
        x, y = grid_xy(s, shape)
        fig.add_shape(
            type="rect",
            x0=x - 0.5 + pad,
            x1=x + 0.5 - pad,
            y0=y - 0.5 + pad,
            y1=y + 0.5 - pad,
            fillcolor=fills[s],
            line_width=0,
            layer="below",
            row=row, col=col
        )
    for s, label in labels.items():
        x, y = grid_xy(s, shape)
        fig.add_annotation(x=x, y=y, text=f"<b>{label}</b>", showarrow=False,
                           font=dict(size=14, color=GRID_INK), row=row, col=col)

def draw_arrows(fig, shape, actions, states, row=1, col=1, color=GRID_ARROW):
    """Draw an arrow in each of the given states, pointing the way its action moves.

    Parameters
    ----------
    fig : plotly.graph_objects.Figure
        A figure from `grid_panels`. It is changed in place.
    shape : tuple of (int, int)
        The grid's (n_rows, n_cols).
    actions : array_like of int, shape (n_rows * n_cols,)
        The action in each state. Only the entries for ``states`` are drawn.
    states : array_like of int
        The states that get an arrow.
    row, col : int, default 1, 1
        The panel to draw into.
    color : str, default GRID_ARROW
        The arrow color.
    """
    subplot = fig.get_subplot(row, col)
    x_ref = subplot.xaxis.plotly_name.replace("axis", "")
    y_ref = subplot.yaxis.plotly_name.replace("axis", "")
    for s in states:
        x, y = grid_xy(s, shape)
        dx, dy = STEP[int(actions[s])]
        fig.add_annotation(
            x=x + 0.34 * dx,
            y=y + 0.34 * dy,
            ax=x - 0.22 * dx,
            ay=y - 0.22 * dy,
            xref=x_ref, yref=y_ref,
            axref=x_ref, ayref=y_ref,
            showarrow=True,
            arrowhead=2, arrowsize=1.0, arrowwidth=2.2, arrowcolor=color
        )

        function).
    shape : tuple of (int, int)
        The grid's (n_rows, n_cols).
    title : str, default ""
        The figure title.

        d3 format spec for the numbers printed in the cells.
    n_panel_cols : int, optional
        Panels per row of the figure. The default puts every panel in one row.
    cell_px : int, default 100

        The plotly template and plot background. GRID_DARK for the book's dark theme.

    Returns
    -------
    plotly.graph_objects.Figure

    fig = grid_panels(list(values), shape, title, n_panel_cols, cell_px, theme)

def grid_step(s, a):
    """Return the state that action `a` leads to from state `s`.

    Moves are deterministic. A move that would step off the grid leaves the agent where it is,
    and a terminal state is absorbing: every action leaves the agent in it.

    Parameters
    ----------
    s : int
        The current state, numbered ``row * n_cols + col`` on the grid.
    a : {UP, DOWN, LEFT, RIGHT}
        The action.

    Returns
    -------
    int
        The next state.
    """
    if s in TERMINAL_STATES:
        return s # terminal = absorbing self-loop
    n_rows, n_cols = GRID_SHAPE
    row, col = divmod(s, n_cols)
    if a == UP: row = max(row - 1, 0)
    elif a == DOWN: row = min(row + 1, n_rows - 1)
    elif a == LEFT: col = max(col - 1, 0)
    elif a == RIGHT: col = min(col + 1, n_cols - 1)
    return row * n_cols + col

P = np.zeros((n_states, n_actions, n_states))
R = np.zeros((n_states, n_actions, n_states))
for s in range(n_states):
    for a in range(n_actions):
        s_next = grid_step(s, a)
        P[s, a, s_next] = 1.0
        if s not in TERMINAL_STATES:
            R[s, a, s_next] = STEP_REWARD_GRID # every move costs this until you reach a corner

# convert into PyTensor
P_sym = pt.as_tensor_variable(P) # (16, 4, 16)
R_sym = pt.as_tensor_variable(R) # (16, 4, 16)
not_terminal = pt.as_tensor_variable((~terminal).astype("float64")) # 1 if not terminal
reward_mean = (P_sym * R_sym).sum(axis=2) # (16, 4)
gamma = pt.scalar("gamma")

Policy evaluation

Given a fixed policy \(\pi\), policy evaluation computes its value function \(v_\pi\) by turning the Bellman expectation equation into an update rule and iterating it to its fixed point:

\[ v_{k+1}(s) \;=\; \sum_a \pi(a\mid s)\sum_{s'} p(s'\mid s,a)\big[r(s,a,s') + \gamma\, v_k(s')\big]. \]

Collapsing the policy into a Markov reward process this linear map

\[ \mathbf v \mapsto \mathbf r^\pi + \gamma P^\pi \mathbf v \]

is a \(\gamma\)-contraction. We run it with pytensor.scan, masking terminal states back to \(0\) each sweep.

We evaluate the equiprobable random policy \(\pi(a\mid s)=\tfrac14\).

pi_sym = pt.matrix("pi") # (16, 4)

# collapse MDP to MRP
P_pi = (pi_sym[:, :, None] * P_sym).sum(axis=1) # (16, 16)
r_pi = (pi_sym * reward_mean).sum(axis=1) # (16,)

def eval_step(v_prev, r_pi, P_pi, gamma, mask):
    """One sweep of iterative policy evaluation on the collapsed Markov reward process.

    Applies the Bellman expectation backup to every state at once,

        v_{k+1}(s) = sum_a pi(a|s) sum_s' p(s'|s, a) [ r(s, a, s') + gamma * v_k(s') ],

    which, with the policy folded into ``r_pi`` and ``P_pi``, is the linear map
    ``v_{k+1} = r^pi + gamma * P^pi v_k``. Here every reward is -1 until a terminal state is
    reached, and the mask pins the two terminal states to 0.

    Parameters
    ----------
    v_prev : TensorVariable, shape (16,)
        The values v_k from the previous sweep.
    r_pi : TensorVariable, shape (16,)
        Expected one-step reward under pi, ``r^pi(s) = sum_a pi(a|s) r(s, a)``.
    P_pi : TensorVariable, shape (16, 16)
        State-to-state transition matrix under pi, ``P^pi[s, s'] = sum_a pi(a|s) p(s'|s, a)``.
    gamma : TensorVariable, scalar
        Discount factor gamma.
    mask : TensorVariable, shape (16,)
        1.0 for a non-terminal state, 0.0 for a terminal one.

    Returns
    -------
    TensorVariable, shape (16,)
        The values v_{k+1}.
    """
    return mask * (r_pi + gamma * pt.dot(P_pi, v_prev)) # mask pins terminals to 0

v_eval_seq = pytensor.scan(
    fn=eval_step,
    outputs_info=pt.zeros((n_states,)), # v_0 = 0
    non_sequences=[r_pi, P_pi, gamma, not_terminal], # not_terminal is our mask in eval_step
    n_steps=600,
    return_updates=False
)
v_eval = v_eval_seq[-1]
evaluate_policy = pytensor.function([pi_sym, gamma], v_eval)

pi_random = np.ones((n_states, n_actions)) / n_actions
v_random  = evaluate_policy(pi_random, GAMMA_GRID)

Policy improvement

Now that we can score a policy, how do we get a better one?

For each state, look one step ahead with the value we just computed and ask which action looks best:

\[ q_\pi(s,a) = \sum_{s'} p(s'\mid s,a)\big[r(s,a,s') + \gamma\, v_\pi(s')\big], \qquad \pi'(s) = \arg\max_a q_\pi(s,a). \]

The policy improvement theorem guarantees \(v_{\pi'} \ge v_\pi\) for every state, with strict improvement somewhere unless \(\pi\) was already optimal. Acting greedily can never make things worse.

Below we make one greedy policy from the random-policy values. Even this single step turns the aimless random walk into something that clearly heads for the corners.

v_sym = pt.vector("v")
q_sym  = (P_sym * (R_sym + gamma * v_sym[None, None, :])).sum(axis=2) # (16, 4)
greedy_sym = q_sym.argmax(axis=1)
q_fn = pytensor.function([v_sym, gamma], [q_sym, greedy_sym])

def greedy_policy(v_val, gamma):
    """Return the deterministic greedy policy with respect to a state-value function.

    Looks one step ahead with the compiled ``q_fn``,

        q(s, a) = sum_s' p(s'|s, a) [ r(s, a, s') + gamma * v(s') ],

    and picks ``argmax_a q(s, a)`` in every state. On this gridworld the moves are deterministic,
    so the sum has a single term. Ties go to the lowest-numbered action.

    Parameters
    ----------
    v_val : ndarray, shape (16,)
        State values v(s).
    gamma : float
        Discount factor gamma.

    Returns
    -------
    pi_new : ndarray, shape (16, 4)
        The policy as a one-hot matrix: 1.0 on the greedy action of each state, 0.0 elsewhere.
    a_star : ndarray of int, shape (16,)
        The greedy action of each state.
    """
    _, a_star = q_fn(v_val, gamma)
    pi_new = np.zeros((n_states, n_actions))
    pi_new[np.arange(n_states), a_star] = 1.0
    return pi_new, a_star

Policy iteration

Policy iteration simply alternates the two steps until the greedy policy stops changing:

\[ \pi_0 \xrightarrow{\text{eval}} v_{\pi_0} \xrightarrow{\text{improve}} \pi_1 \xrightarrow{\text{eval}} v_{\pi_1} \xrightarrow{\text{improve}} \cdots \xrightarrow{} \pi_* . \]

Because there are finitely many deterministic policies and each round strictly improves (or we stop), it converges to an optimal policy in a handful of iterations. On this gridworld the random policy already points roughly the right way, so it lands on \(\pi_*\) almost immediately.

pi = np.ones((n_states, n_actions)) / n_actions  # start from the random policy
for iteration in range(50):

    pi_new, a_star = greedy_policy(v_val, GAMMA_GRID) # improvement (greedy)

    if np.array_equal(pi_new, pi):
        print(f"policy stable after {iteration} improvement step(s)")
        break
    pi = pi_new

Value iteration

Policy iteration runs evaluation to convergence inside every step - often overkill. Value iteration truncates evaluation to a single sweep and folds the improvement straight into it by using the Bellman optimality backup (a max instead of the policy average):

\[ v_{k+1}(s) = \max_a \sum_{s'} p(s'\mid s,a)\big[r(s,a,s') + \gamma\, v_k(s')\big]. \]

It is the same max-backup we used for the recycling robot. On the gridworld it reaches \(v_*\) in just a few sweeps - the longest shortest-path is 6 moves, and information propagates one cell per sweep.

def vi_step(v_prev, P_sym, R_sym, gamma, mask):
    """One synchronous sweep of value iteration.

    Applies the Bellman optimality backup to every state at once, computed from the old values
    v_k only:

        v_{k+1}(s) = max_a sum_s' p(s'|s, a) [ r(s, a, s') + gamma * v_k(s') ].

    Here every reward is -1 until a terminal state is reached, and the mask pins the two
    terminal states to 0.

    Parameters
    ----------
    v_prev : TensorVariable, shape (16,)
        The values v_k from the previous sweep.
    P_sym : TensorVariable, shape (16, 4, 16)
        Transition probabilities p(s'|s, a).
    R_sym : TensorVariable, shape (16, 4, 16)
        Rewards r(s, a, s').
    gamma : TensorVariable, scalar
        Discount factor gamma.
    mask : TensorVariable, shape (16,)
        1.0 for a non-terminal state, 0.0 for a terminal one.

    Returns
    -------
    TensorVariable, shape (16,)
        The values v_{k+1}.
    """
    q = (P_sym * (R_sym + gamma * v_prev[None, None, :])).sum(axis=2) # (16, 4)
    return mask * q.max(axis=1)

v_vi_seq = pytensor.scan(
    fn=vi_step,
    outputs_info=pt.zeros((n_states,)),
    non_sequences=[P_sym, R_sym, gamma, not_terminal],
    n_steps=100,
    return_updates=False
)

deltas = np.abs(np.diff(v_per_sweep, axis=0)).max(axis=1)

A richer test: the Gambler’s Problem

The gridworld is so easy that policy iteration finishes in one step.

The Gambler’s Problem has a far more interesting optimal value/policy, and is the classic showcase for value iteration.

A gambler bets on coin flips.

  • State: current capital \(s \in \{0,\dots,100\}\)
  • action: the stake/bet \(a \in \{0,1,\dots,\min(s,\,100-s)\}\)

On each flip the coin comes up heads with probability \(p_h\). Heads adds the stake to the gambler’s capital, tails loses it. The episode ends at \(\$0\) (lose) or \(\$100\) (win); the reward is \(0\) everywhere except \(+1\) on reaching \(\$100\). Undiscounted, \(\gamma = 1\).

We use \(p_h = 0.4\) an unfair coin, so in the long run we expect to lose money.

Note

The cap on the stake is due to having no benefit to exceeding $100.

P_HEADS = 0.4
GOAL = 100
n_states_gambler = GOAL + 1
stakes = np.arange(0, GOAL // 2 + 1) # possible stakes 0 through 50

S = np.arange(n_states_gambler)[:, None] # (101, 1) capital
A = stakes[None, :] # (1, 51) stake
next_if_heads = np.clip(S + A, 0, GOAL) # next capital on heads
next_if_tails = np.clip(S - A, 0, GOAL) # next capital on tails
valid = (A >= 1) & (A <= np.minimum(S, GOAL - S)) # non-zero stakes

next_if_heads_sym = pt.as_tensor_variable(next_if_heads)
next_if_tails_sym = pt.as_tensor_variable(next_if_tails)
valid_sym = pt.as_tensor_variable(valid.astype("float64"))
p_h_sym = pt.scalar("p_h")

terminal_gambler = (np.arange(n_states_gambler) == 0) | (np.arange(n_states_gambler) == GOAL) # terminal states are $0 and $100
terminal_gambler_sym = pt.as_tensor_variable(terminal_gambler.astype("float64"))
V_terminal = np.zeros(n_states_gambler)
V_terminal[GOAL] = 1.0  # All values 0 except when capital is $100
V_terminal_sym = pt.as_tensor_variable(V_terminal)
NEG_INF = -1e30 # stand-in for -inf when masking illegal stakes

def gambler_vi(V_prev, next_if_heads, next_if_tails, valid, p_h, V_terminal, terminal_mask):
    """One synchronous sweep of value iteration on the gambler's problem.

    The Bellman optimality backup is

        V_{k+1}(s) = max_a sum_s' p(s'|s, a) [ r(s, a, s') + gamma * V_k(s') ].

    Here gamma = 1, a stake a leads to s + a with probability p_h and to s - a otherwise, and
    the reward is 0 on every flip: the +1 for reaching $100 is stored as the terminal value
    V(100) = 1 instead. So the backup becomes

        V_{k+1}(s) = max_a [ p_h * V_k(s + a) + (1 - p_h) * V_k(s - a) ],

    with the max taken over the legal stakes ``1 <= a <= min(s, 100 - s)`` only. The terminal
    capitals $0 and $100 keep their fixed values.

    Parameters
    ----------
    V_prev : TensorVariable, shape (101,)
        The values V_k from the previous sweep, one per capital 0..100.
    next_if_heads, next_if_tails : TensorVariable of int, shape (101, 51)
        The next capital after heads (``s + a``) and after tails (``s - a``), by capital and stake.
    valid : TensorVariable, shape (101, 51)
        1.0 where the stake is legal in that capital, 0.0 elsewhere.
    p_h : TensorVariable, scalar
        Probability of heads, p_h.
    V_terminal : TensorVariable, shape (101,)
        The fixed terminal values: 1.0 at $100, 0.0 everywhere else.
    terminal_mask : TensorVariable, shape (101,)
        1.0 at the terminal capitals $0 and $100, 0.0 elsewhere.

    Returns
    -------
    TensorVariable, shape (101,)
        The values V_{k+1}.
    """
    q = p_h * V_prev[next_if_heads] + (1.0 - p_h) * V_prev[next_if_tails] # (101, 51)
    q = pt.where(valid > 0, q, NEG_INF) # mask illegal stakes
    V_max = q.max(axis=1)
    return terminal_mask * V_terminal + (1.0 - terminal_mask) * V_max # keep terminals pinned

Asynchronous DP

The methods above do synchronous (Jacobi) sweeps where we compute every \(v_{k+1}(s)\) from the old \(v_k\), using two copies of the array.

Asynchronous DP updates states in place, one at a time, in any order, reusing the freshest values immediately. As long as every state keeps getting visited it still converges, and it often needs fewer updates because new information propagates within a sweep instead of waiting for the next one.

Here is the in-place (Gauss-Seidel) version of value iteration where we use an inner scan over states that uses set_subtensor to assign each new value back into the same vector, so a state updated early in the sweep is already visible to states updated later.

def inplace_state_update(s, V, P_sym, R_sym, gamma, mask):
    """Apply the Bellman optimality backup to one state and write the result back into V.

        V(s) <- max_a sum_s' p(s'|s, a) [ r(s, a, s') + gamma * V(s') ]

    ``V`` already holds the new values of the states updated earlier in this sweep, so the
    backup uses the freshest value of every next state. Here every reward is -1 until a terminal
    state is reached, and the mask pins the two terminal states to 0.

    Parameters
    ----------
    s : TensorVariable of int, scalar
        The state to update, supplied by the scan sequence.
    V : TensorVariable, shape (16,)
        The current values, partly updated this sweep.
    P_sym : TensorVariable, shape (16, 4, 16)
        Transition probabilities p(s'|s, a).
    R_sym : TensorVariable, shape (16, 4, 16)
        Rewards r(s, a, s').
    gamma : TensorVariable, scalar
        Discount factor gamma.
    mask : TensorVariable, shape (16,)
        1.0 for a non-terminal state, 0.0 for a terminal one.

    Returns
    -------
    TensorVariable, shape (16,)
        ``V`` with entry ``s`` replaced by its new value.
    """
    q_s = (P_sym[s] * (R_sym[s] + gamma * V[None, :])).sum(axis=1) # (n_actions,)
    new_value = mask[s] * q_s.max()
    return pt.set_subtensor(V[s], new_value) # write back in place

def inplace_sweep(V_in, P_sym, R_sym, gamma, mask):
    """One in-place (Gauss-Seidel) sweep of value iteration.

    Updates the states one at a time, in the order 0, 1, ..., 15, with `inplace_state_update`.
    Each new value is written into the same vector straight away, so a state updated late in the
    sweep already sees the new values of the states updated before it.

    Parameters
    ----------
    V_in : TensorVariable, shape (16,)
        The values at the start of the sweep.
    P_sym : TensorVariable, shape (16, 4, 16)
        Transition probabilities p(s'|s, a).
    R_sym : TensorVariable, shape (16, 4, 16)
        Rewards r(s, a, s').
    gamma : TensorVariable, scalar
        Discount factor gamma.
    mask : TensorVariable, shape (16,)
        1.0 for a non-terminal state, 0.0 for a terminal one.

    Returns
    -------
    TensorVariable, shape (16,)
        The values after every state has been updated once.
    """
    V_seq = pytensor.scan(
        fn=inplace_state_update,
        sequences=[pt.arange(n_states)],
        outputs_info=V_in,
        non_sequences=[P_sym, R_sym, gamma, mask],
        return_updates=False
    )
    return V_seq[-1]

V_in = pt.vector("V_in")
one_sweep = pytensor.function([V_in, gamma], inplace_sweep(V_in, P_sym, R_sym, gamma, not_terminal))

V = np.zeros(n_states)

Generalized Policy Iteration (GPI)

Step back and notice everything we built is the same dance between two processes:

  • evaluation drives \(v\) toward \(v_\pi\) (make the value consistent with the policy),
  • improvement drives \(\pi\) toward greedy(\(v\)) (make the policy consistent with the value).

GPI is the umbrella term for letting these two interact at any granularity:

how many evaluation sweeps per improvement? algorithm
infinite (evaluate to convergence) policy iteration
exactly \(1\) value iteration
some \(k\) in between truncated policy iteration
in place / arbitrary order asynchronous DP

They all chase the same fixed point - the single \((v_*, \pi_*)\) where both consistency conditions hold at once.

Summary & Recap

We implemented the chapter material on top of the same PyTensor MDP machinery from the previous chapter:

  • policy evaluation: iterate the expectation backup to \(v_\pi\)
  • policy improvement: greedy step, justified by the improvement theorem
  • policy iteration: alternate the two to \(\pi_*\)
  • value iteration: one-sweep evaluation via the optimality max-backup
  • asynchronous DP: in-place Gauss-Seidel updates, same fixed point in (theoretically) fewer sweeps
  • GPI: the unifying frame; every method above is one knob setting of “eval sweeps per improvement”
